# ontology-map 역사 문서

이 디렉터리는 완료된 계획, 과거 대화 기록과 정식 문서에 결론이 반영된 Issue별 설계 문서를 보존한다. 새 세션의 기본 읽기 대상이 아니며 현재 계약의 근거로 단독 사용하지 않는다.

현재 계약은 [문서 안내](../docs/README.md)에 등록된 제품, 아키텍처, 데이터, 운영과 개발 문서를 우선한다. 내용이 충돌하면 승인된 frozen schema, 병합된 코드와 최신 GitHub 결정 순으로 다시 확인한다.

## 보존 범위

- `ontology-map-design-conversation-transcript.md`: 디자인 계약을 만들 때의 전체 대화 기록
- `people-intelligence-requirements-transcript.md`: 초기 요구사항과 데이터 모델 결정 과정
- `people-intelligence-requirements-traceability.md`: Logical Schema v1 당시의 요구사항 추적표
- `logical-schema/`: #91 인사이트 확장 전용 문서. 현재 결론은 루트 논리 스키마에 통합했다.
- `physical-schema/`: #41–#48, #78과 #91의 단계별 물리 설계·통합 검증 문서. 현재 결론은 루트 물리 스키마에 통합했다.

새 역사 문서를 주제별로 추가하지 않는다. 현재 계약은 먼저 정식 문서에 반영하고, 보존할 명확한 이유가 있는 기존 산출물만 이 디렉터리로 옮긴다.
